# Source Implementation

This directory is reserved for the actual Asterra game source.

## v0.2

The immediate implementation target is the multi-generation starter system documented in `docs/STARTER_SYSTEM_V0.2.md` and `docs/v0.2_IMPLEMENTATION.md`.

The repository must eventually contain the complete buildable FireRed-derived source tree needed to produce the final `.gba`. Do not commit a copyrighted base ROM.

## Build requirement

Every release candidate must produce a standard Game Boy Advance `.gba` and pass the GBA compatibility checklist before being called playable.
