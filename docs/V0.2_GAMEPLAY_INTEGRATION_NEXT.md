# v0.2 Gameplay Integration — Next Milestone

The GBA build pipeline now completes successfully. This document defines the next source-level gameplay milestone.

## Objective

Replace the normal FireRed opening starter flow with the Asterra starter sequence while preserving FireRed's native script, party, and trainer-battle systems.

## Required player flow

1. New Game starts in the Asterra opening.
2. Professor Lyra introduces the starter choice.
3. Player selects Generation I, II, or III.
4. Player selects one of the three starters from that generation.
5. The selected species is given as a level-5 party Pokémon.
6. The selection is stored in the appropriate game variables/state.
7. Nova receives the predefined counter species for that generation/choice.
8. Nova's native trainer battle begins.
9. After the battle, the story proceeds toward the first Asterra town and Route 1.

## Starter mapping

Generation I: Bulbasaur / Charmander / Squirtle
Generation II: Chikorita / Cyndaquil / Totodile
Generation III: Treecko / Torchic / Mudkip

## Counter mapping

Bulbasaur -> Squirtle
Charmander -> Bulbasaur
Squirtle -> Charmander
Chikorita -> Totodile
Cyndaquil -> Chikorita
Totodile -> Cyndaquil
Treecko -> Mudkip
Torchic -> Treecko
Mudkip -> Torchic

## Acceptance criteria

The milestone is not considered playable until a freshly built GBA:

- boots normally;
- reaches the Asterra starter scene from a new game;
- exposes all three generation choices;
- exposes all three starters for each selected generation;
- gives exactly the selected Pokémon at level 5;
- gives Nova the correct counter;
- starts the native trainer battle;
- returns to the overworld after battle without corrupting the save;
- reaches the intended first-route continuation.

Until these criteria pass in an emulator, source files are considered integration work rather than a released playable v0.2 ROM.
