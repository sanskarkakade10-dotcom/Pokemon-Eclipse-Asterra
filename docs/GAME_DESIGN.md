# Pokémon Eclipse — Game Design

## Vision

Pokémon Eclipse is a new adventure built on the FireRed gameplay foundation but designed around an original region, story and progression.

The goal is to preserve the strengths of Generation III while adding a broader Pokémon ecosystem, stronger narrative identity and modern quality-of-life features.

## Core gameplay

- Traditional turn-based Pokémon battles.
- Exploration-driven progression.
- Eight regional Gym challenges, followed by an Elite Four and Champion.
- Optional side quests and post-game exploration.
- Wild Pokémon and trainer teams designed around Asterra's regional ecology.

## Starter philosophy

The classic Kanto starters are not discarded. Bulbasaur, Charmander and Squirtle remain the iconic foundation.

The planned starter selector will expand this into generation-based pools. The player will choose a generation/pool and then select a starter from that pool. Nova will receive a suitable counter based on the player's selection.

Initial target pools:

- Generation I — Bulbasaur / Charmander / Squirtle
- Generation II — Chikorita / Cyndaquil / Totodile
- Generation III — Treecko / Torchic / Mudkip

Later generations can be added once the underlying species/data system is ready.

## Eclipse system

The Eclipse Cycle is the game's central world mechanic. Story events, legendary Pokémon and certain areas will be tied to eclipse phases.

Potential future gameplay uses include:

- special encounters
- altered Pokémon forms
- hidden areas
- time/event-based NPC behavior
- unique Team Umbra operations

## Design rule

A feature should be implemented as a real game mechanic whenever practical. Cosmetic text changes are useful for prototypes but should not be mistaken for finished gameplay systems.
