# v0.2 Build Gate

The v0.2 branch is not considered playable until all of these are true:

- [ ] Complete FireRed-derived source tree is available to the build.
- [ ] Native generation menu is integrated.
- [ ] Native starter menu is integrated.
- [ ] All 9 Gen I–III choices give the correct species at level 5.
- [ ] Starter generation/choice persists through map changes.
- [ ] Nova's counter is correct for all 9 choices.
- [ ] Nova's battle uses the intended trainer party.
- [ ] Fresh-save progression reaches the first Asterra route.
- [ ] Save/load works after receiving the starter.
- [ ] GitHub Actions successfully builds a `.gba`.
- [ ] The resulting `.gba` boots in mGBA.
- [ ] The resulting `.gba` is tested in the target browser emulator.

## Why this gate exists

The upstream pret/pokefirered project is a source decompilation that builds a
normal GBA ROM; its documented FireRed v1.0 build has SHA-1
41cb23d8dccc8ebd7c649cd8fbb58eeace6e2fdc. We use that source architecture,
not a browser-specific runtime.

The Asterra repository must not distribute the original copyrighted FireRed
ROM. A user supplies a compatible base/build input locally.
