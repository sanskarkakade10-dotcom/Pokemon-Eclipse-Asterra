# v0.2 One-Go Integration Plan

This is the implementation contract for the first playable Eclipse prototype. It deliberately separates source integration from the copyrighted base ROM: the FireRed decompilation is fetched by the build workflow and is not committed here.

## Deliverable

A reproducible build must produce `Pokemon-Eclipse-Asterra-v0.2.gba` from the pinned FireRed source plus the Asterra overlay.

## Opening sequence

1. Existing FireRed opening reaches the starter-lab scene.
2. Eclipse replaces the presentation with Professor Lyra/Asterra dialogue.
3. Generation menu offers I, II and III.
4. A second menu offers the three starters for the selected generation.
5. Confirmation gives exactly one level-5 starter.
6. Generation and starter index are stored in game variables.
7. Nova's opening trainer is resolved from the same generation and the counter mapping.
8. Native FireRed trainer-battle machinery starts the rival battle.
9. On battle completion the story proceeds to the first Asterra route.

## Required native engine pieces

- Map script replacement for the starter-lab scene.
- Menu constants/text entries.
- Script variables for generation, starter index and confirmation state.
- Native `givemon`/party operation.
- Nine Nova trainer configurations, or a validated dynamic trainer-party path if the pinned source supports it cleanly.
- Native trainer-battle invocation.
- Post-battle route transition.

## Build gate

The integration must not be called playable until CI produces a `.gba` and automated source checks pass. Emulator testing is a separate release gate.

## No-ROM policy

Do not commit, publish, or embed the original FireRed `.gba` in this repository. Users supply their own compatible base for local development where required by the build workflow/license.
