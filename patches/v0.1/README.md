# v0.1 Patch

The v0.1 playable prototype was developed against the user's English Pokémon FireRed v1.0 (BPRE) base ROM.

The repository does not include the ROM itself. The final distribution format should be a patch that the user applies to their own compatible base ROM.

## v0.1 scope

- Asterra identity/text foundation
- Aster Haven / Eclipse Haven naming direction
- Nova rival naming direction
- Multi-generation starter concept
- Route 1 encounter prototype

## Important

The real multi-generation starter selector is a v0.2 implementation target. v0.1 should be treated as a foundation/prototype rather than a finished release.
